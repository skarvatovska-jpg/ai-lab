# Career-TwinNavigatorBot - Інструкція з запуску

## 📋 Опис проекту

Career-TwinNavigatorBot — Telegram-бот для вибору кар'єри на основі поведінкового аналізу та прогнозування ризику вигорання (Burnout).

## 🛠 Технології

- **Python 3.10+**
- **aiogram 3.4.1** — фреймворк для Telegram бота
- **OpenAI API** — для аналізу поведінки та генерації сценаріїв
- **SQLite** — база даних (легко замінити на PostgreSQL)
- **pydantic** — валідація даних

## 📁 Структура проекту

```
project/
├── main.py                    # Головний файл запуску
├── config.py                  # Конфігурація та змінні середовища
├── database.py                # Модуль роботи з БД
├── requirements.txt           # Залежності Python
├── env.example                # Приклад файлу змінних середовища
├── bot/
│   ├── __init__.py
│   ├── handlers.py            # Обробники команд та повідомлень
│   └── states.py              # FSM стани
└── ai_engine/
    ├── __init__.py
    ├── behavior_analyzer.py   # Аналіз поведінкового вектора
    ├── scenario_generator.py  # Генерація сценаріїв
    └── burnout_predictor.py   # Прогноз ризику вигорання
```

## 🚀 Встановлення та запуск

### Крок 1: Встановлення Python

Переконайтесь, що у вас встановлено Python 3.10 або новіший:
```bash
python --version
```

### Крок 2: Створення віртуального середовища

```bash
cd project
python -m venv venv

# Windows
venv\Scripts\activate

# Linux/Mac
source venv/bin/activate
```

### Крок 3: Встановлення залежностей

```bash
pip install -r requirements.txt
```

### Крок 4: Отримання API ключів

1. **Telegram Bot Token:**
   - Відкрийте Telegram та знайдіть [@BotFather](https://t.me/BotFather)
   - Надішліть команду `/newbot`
   - Дотримуйтесь інструкцій та скопіюйте отриманий токен

2. **OpenAI API Key:**
   - Зареєструйтесь на [platform.openai.com](https://platform.openai.com)
   - Перейдіть до розділу API Keys
   - Створіть новий ключ та скопіюйте його

### Крок 5: Налаштування змінних середовища

Створіть файл `.env` в папці `project/` на основі `env.example`:

```env
BOT_TOKEN=ваш_telegram_bot_token
OPENAI_API_KEY=ваш_openai_api_key
DATABASE_PATH=career_twin.db
OPENAI_MODEL=gpt-4o-mini
```

⚠️ **Важливо:** Ніколи не публікуйте файл `.env` в Git!

### Крок 6: Запуск бота

```bash
python main.py
```

Якщо все налаштовано правильно, ви побачите:
```
INFO - Запуск Career-TwinNavigatorBot...
INFO - База даних ініціалізована
INFO - Бот готовий до роботи!
```

### Крок 7: Тестування

1. Відкрийте Telegram
2. Знайдіть вашого бота за ім'ям, яке ви дали @BotFather
3. Надішліть команду `/start`
4. Почніть тестування анкети та симуляцій

## 📊 Як працює бот

### 1. Анкета (Створення цифрового двійника)
- Користувач відповідає на 4 питання про поведінку
- AI аналізує відповіді та формує поведінковий вектор (аналог Big5)
- Зберігається у базі даних

### 2. Вибір ролі
- Бот пропонує 5 рекомендованих професій
- Користувач обирає одну для симуляції

### 3. Симуляція
- AI генерує реалістичний стресовий сценарій
- Користувач обирає свою реакцію
- AI аналізує відповідь

### 4. Результат
- Оцінка сумісності (0-100%)
- Прогноз ризику вигорання (низький/середній/високий)
- Сильні та слабкі сторони
- Конкретні рекомендації

## 🔧 Налаштування

### Зміна моделі OpenAI

У файлі `.env` можна змінити модель:
- `gpt-4o-mini` — швидка та економна (рекомендовано для тестування)
- `gpt-4o` — точніша, але дорожча
- `gpt-3.5-turbo` — альтернатива

### Заміна SQLite на PostgreSQL

1. Встановіть `asyncpg`:
```bash
pip install asyncpg
```

2. Змініть `database.py` для використання PostgreSQL замість SQLite

## 🐛 Розв'язання проблем

### Помилка "BOT_TOKEN не встановлено"
- Перевірте, що файл `.env` існує та містить правильний токен
- Переконайтесь, що файл знаходиться в папці `project/`

### Помилка з OpenAI API
- Перевірте, що API ключ валідний
- Переконайтесь, що на вашому рахунку є кошти
- Перевірте rate limits

### Бот не відповідає
- Перевірте, що бот запущено (`python main.py`)
- Переконайтесь, що токен правильний
- Перевірте логи на наявність помилок
