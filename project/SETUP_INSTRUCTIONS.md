## 📝 Що потрібно зробити ДАЛІ:

### Крок 1: Створіть файл `.env`

Файл `.env` потрібно створити вручну, тому що він містить секретні ключі і не зберігається в Git.

**Варіант 1 (Windows PowerShell):**
```powershell
cd project
Copy-Item env.example .env
notepad .env
```

**Варіант 2 (вручну):**
1. Відкрийте папку `project`
2. Скопіюйте файл `env.example` та перейменуйте на `.env`
3. Відкрийте `.env` у текстовому редакторі

### Крок 2: Отримайте API ключі

#### Telegram Bot Token:
1. Відкрийте Telegram
2. Знайдіть [@BotFather](https://t.me/BotFather)
3. Надішліть команду `/newbot`
4. Слідуйте інструкціям
5. Скопіюйте отриманий токен

#### OpenAI API Key:
1. Зареєструйтесь на [platform.openai.com](https://platform.openai.com)
2. Перейдіть до розділу "API Keys"
3. Створіть новий ключ
4. Скопіюйте ключ

### Крок 3: Заповніть `.env` файл

Відредагуйте `.env` файл та вставте свої ключі:

```env
BOT_TOKEN=ваш_реальний_токен_від_BotFather
OPENAI_API_KEY=ваш_реальний_ключ_від_OpenAI
DATABASE_PATH=career_twin.db
OPENAI_MODEL=gpt-4o-mini
```

### Крок 4: Запустіть бота

**Windows:**
```powershell
cd project
.\venv\Scripts\Activate.ps1
python main.py
```

**Або використайте готовий скрипт:**
```powershell
.\start.bat
```

**Linux/Mac:**
```bash
cd project
source venv/bin/activate
python main.py
```

## 🐛 Вирішення проблем:

### Помилка "BOT_TOKEN не встановлено"
- Перевірте, що файл `.env` існує в папці `project/`
- Переконайтесь, що токени не містять зайвих пробілів
- Перевірте, що файл називається саме `.env` (з крапкою на початку)

### Помилка з OpenAI API
- Перевірте, що API ключ правильний
- Переконайтесь, що на рахунку є кошти
- Перевірте rate limits

### Бот не відповідає
- Перевірте, що бот запущено
- Переконайтесь, що токен правильний
- Перевірте логи на помилки
